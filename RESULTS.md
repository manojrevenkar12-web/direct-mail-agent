## The first held-out run (`heldout`, spent)

The first version ran once on `heldout` (`config/heldout.lock`, commit 427c438) and earned +4.1% over today's process, against +14.3% for learning without holdouts. Two design flaws, both mine: every cell started from the same prior, ignoring the existing predictive models (in round 1 it filled the cells the models rank lowest), and cells kept only for learning had about 110 held-out businesses, too few to tell anything at application rates under 1%, so a good cell written off early never came back. The fix starts every cell from the models' prediction, ranks by the mailed arm and keeps a small holdout for measurement. Because the fix was found on `heldout`, that split is spent; `heldout2` was defined before the fixed agent ran on anything but `dev`.
